- Build strong programming and problem-solving skills using Python.
- Master Python fundamentals and explore advanced Python concepts.
- Learn SQL for data querying and analysis.
- Perform data cleaning, manipulation, and exploratory data analysis.

- Database fundamentals and SQL queries

- Joins and subqueries
- Window functions
- Practical SQL case studies

### 4. NumPy
- Array creation, indexing, and slicing
- Vectorized operations

- Practical NumPy exercises and projects

### 5. Data Analysis & EDA with Pandas
- Loading and inspecting datasets

- Handling missing values and cleaning data
- Feature creation and transformation

### 6. Data Visualization
- Line charts and bar charts

- Population, sample, and descriptive statistics

### 10. Generative AI & Prompt Engineering
- Introduction to Large Language Models (LLMs)

### 11. RAG, AI Agents & MCP
- Retrieval-Augmented Generation (RAG)

### 12. Projects & Deployment

- Deploying projects and creating a portfolio
